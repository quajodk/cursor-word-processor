Decisions on the record

Editor engine

ProseMirror, used directly — not Tiptap, not Lexical

Pure decorations are load-bearing for AI diffs, diagnostics and blame. Lexical and Quill lack them; Tiptap's auto-schema fights the OOXML mapping.

The docx tension

Splice the original zip; never regenerate it

Turns 'how much OOXML can we model?' into 'how little must we touch?'. An unedited round-trip is byte-identical, and fidelity degrades only in proportion to what was actually edited.

Anchors

Exact in-session, fuzzy only for externally-edited files

While the doc is open we observed every change, so identity needs no guessing. Sequence alignment is reserved for files edited by another tool — that split is what makes the problem tractable.

Confidence floor

Drop formatting rather than risk misapplying it

A dropped style is a visible bug the writer can fix; a misapplied one silently corrupts a document they trusted.

Diagnostics

harper.js in a worker, behind an LSP-shaped seam

Offline, Apache-2.0, works unchanged in web v1 and Tauri v2. The LSP shape makes adding a second checker cheap.

Perf honesty

A measurement that covers only part of a path may fail a budget but may never certify a pass

A headless process cannot see the DOM half of a keystroke. Reporting it as 'pass' would manufacture confidence in a number that never measured the thing it names.

Scoring honesty

A tier entailed by another tier is labelled, not counted twice

Scriv’s T2 is 1.0000 because T0 is 100% — T2 scores the zero-edit round trip that T0 already proved byte-identical. Presenting both as achievements would inflate one fact into two.

Measuring a budget

A budget that names a size needs an upper bound on the band, and warm-up is reported separately rather than folded in

“50-page” measured as “≥500 paragraphs” swept in 11,000-paragraph documents and reported a failure three times the real one; a bench with no warm-up puts JIT cost in the p99 tail and blames the code for it.

Key bindings

Verified by pressing them in the running app, not by reading a table

Mod-Ctrl-ArrowUp looked ideal for expand-selection and is silently eaten by Mission Control on macOS. The keys the OS takes are now listed in the binding table so they are not rediscovered.

Typecheck graph

Every package is a referenced project, not just the ones that happened to be listed

Four packages including the largest were outside the root tsconfig references, so every clean typecheck was checking a subset. Adding them surfaced 114 errors, three of which were real defects.

Completion restraint

The popup never opens on a bare word, at any length

Every threshold low enough to be useful is low enough to interrupt an ordinary sentence. Code completion can fire on every identifier character because a programmer is always naming something; a writer usually is not.

Perf gating

The gate will not fail on a percentile its own sample size cannot support

docx throughput measured 1.299, 1.841 and 2.281 ms across three runs of identical code. With 227 samples a p99 rests on about three order statistics. A gate that fails at random teaches people to re-run until it passes.

AI suggestions

Rendered with the schema’s existing tracked-change marks, not a parallel mechanism

Accepting an AI rewrite and accepting a colleague’s tracked change become one code path, an AI suggestion exports to Word as a real revision, and undo and position mapping already understand it.

Diagnostics

Squiggles are decorations, and the checker declines languages it cannot handle

A squiggle in the document would be savable, undoable and exportable to Word. And running an English checker over Hindi produces a wall of false errors, which is worse than no diagnostics at all.

Prose git

A newline inside a block is a soft wrap, not a sentence boundary

Treating it as one made reflowing a paragraph produce a diff — defeating the entire purpose — and hid every mixed-authorship sentence from blame, since each fragment sat on its own line.

Multi-cursor

The primary cursor stays a real selection; extra cursors are plugin state drawn as decorations

A Selection subclass holding N ranges is the “proper” answer and breaks everything downstream — the view draws one native selection, and baseKeymap, input rules and mark logic all read the primary range.

Images

Inline, not block

Markdown’s linked badge is a link wrapping an image and OOXML’s drawing sits inside a run. Modelling images as blocks forced every in-paragraph image to split it, and the enclosing link mark had nowhere to live — so saving a file deleted the hyperlink.

Palette

Derived from the binding table, not maintained beside it

Thirty text operations had a key and no palette entry, and two of them were bound to chords macOS eats — so they could not be invoked at all. Deriving the palette from the table means a binding cannot exist without being discoverable.

Notes

  • OffsetMap was wrong and a new test caught it. It emitted a separator for every BLOCK; textBetween emits one only before a TEXTBLOCK. A bullet list with four items is nine blocks and four textblocks — so in any document containing a list the map drifted by one position per extra wrapper, and every diagnostic, every AI hunk and every extra cursor after the first list landed on the wrong word. Nothing threw. The agreement is now checked character by character over 25 real documents.
  • The incremental linter was expected to match a whole-document lint exactly. On real prose it does not — 4 diagnostics in 200 — and the difference runs the other way: Harper does not treat a bare newline as a sentence end, so the joined document merged two speakers' dialogue into one '52-word sentence' warning while hiding a lowercase sentence start, a misspelling and a repeated word inside the paragraphs it had glued together. The test now asserts that every difference is a block-boundary artefact, checked causally by re-linting the glued reading.
  • The completion bench's first workspace was 400 files taken in glob order. It got handed 374 three-line CommonMark spec fixtures and produced 13 symbols between them — a workspace number that was really the single-document number, which is the exact failure the workspace was added to avoid.
  • Making images render broke the splice engine — T0 fell from 60/60 byte-identical to 54/60 — and the assertion added an hour earlier caught it. The exporter keys its verbatim-copy path on the sidecar’s recorded block kind, which the import had stopped recording. That is what a gate is for.
  • An independent audit found two of four house rules violated, a security defect, and the headline fidelity metric ungated. It was right on all three. The worst: saving an unedited Markdown file was DELETING hyperlinks from CI badges — silent data loss in the layer this project calls the source of truth. I had seen the symptom myself, filed it as a pre-existing limitation, and moved on.
  • Two gates could not fail. Formatting preservation was printed but never asserted — the auditor broke the exporter and 23 documents lost their formatting with the suite still green. And no test file was in the typecheck graph at all, so a deliberate type error in a test passed cleanly.
  • The blind comparison cannot be run here: it needs the same task performed in Cursor, Google Docs and Obsidian by an operator. Our leg of it is done and the artefact exists — a revised .docx from a real consultation document, with every part except the body text byte-identical.
  • Every “select all occurrences” was off by one: converting a text offset back to a position by binary search can land BEFORE a paragraph rather than at its first character, so an occurrence at the start of a block failed to match the primary selection and was added twice. Writing a third copy of a mapping two packages already shared was the mistake.
  • Every git call with an omitted trailing argument was failing: JSON.stringify turns an undefined array element into null, so the server’s “=== undefined” check never matched. That affected the whole dispatch table, not just the call that happened to expose it.
  • Move detection had never fired: the longest-increasing-subsequence used each pair’s index in the array as its value, which is increasing by construction, so every pair was always kept and nothing was ever reported as moved.
  • Moving a shared helper into doc-model broke an import in a test file. The file then failed to LOAD, which silently removed ten tests from the aggregate while the run still exited zero — caught only by noticing the total had fallen when it should have risen.
  • Cmd-K collided with “insert link”, which is the conventional binding in a word processor and also the conventional AI-rewrite binding in an IDE. The rewrite won it; the link moved to Cmd-Shift-K. Submitting then did nothing, because the code read the live selection after focus had moved to the prompt field.
  • The prose diff started at 5/174 on reconstructing real edits and reached 174/174 through three fixes, each a case where the tidier behaviour was the wrong one — most tellingly, word spans that absorbed their own spacing produced a cleaner diff that did not reproduce what the model actually returned.
  • The completion popup found three bugs by being used rather than read: accepting a citation produced “@@key” because the replacement range started after the sigil, the popup ran off the window edge, and the detail line printed an absolute filesystem path.
  • Entity detection without a stop-word list took three attempts against real documents. The top “entities” in a 40-document sample were initially Fix, Add, The and This — a capital is explained by position, and in reference documentation a closing bracket or dash explains one as completely as a full stop does.
  • A Word document now opens, edits and saves in the app, touching exactly one of its twenty zip parts. That is the hard requirement, demonstrated through the UI rather than a benchmark.
  • packages/ooxml, textops, workspace and perf were never in the typecheck graph. Every “typecheck clean” reported before this wave was checking five of nine projects and excluding the largest. Now all nine are referenced and clean.
  • Two bugs in the selection ladder were found by testing rather than reading: it walked back down once a selection spanned two paragraphs, and selecting the whole document used a position that sits between nodes rather than inside text. Both are now asserted by tests.
  • The perf gate went from red to green through three changes, only one of which was an optimisation: discarding warm-up (3352→2364 ms), bounding the 50-page band so it stopped including 500-page documents (→1260 ms), and removing per-part hashing that nothing read (→670 ms).
  • A check of mine reported three documents losing right-to-left run formatting. Reading the XML showed the opposite: the exporter had dropped a second, completely empty run carrying only that property and no text, which is correct. The comparison was wrong, not the exporter — it compared whole property payloads, which cannot tell a legitimate run merge from a real loss. It now compares property names, and that invariant is enforced by a test.
  • The splice design is validated: on real Word documents an unedited round trip is byte-identical, and a one-word edit changes exactly one paragraph. Pandoc, which regenerates, scores 0% on both — while remaining self-consistent at 0.9913 against its own output, so this is not a strawman: it preserves its own conversion faithfully, just not the user's document.
  • The gate is currently RED, deliberately and correctly: importing large Word documents takes p99 3.35s against a 1.2s budget. A 84ms average across the whole corpus had hidden this — the large documents are the bottleneck.
  • A status-bar reading that looked like two bugs turned out to be the 220 ms coalescing timer doing its job — the status store deliberately keeps typing off React’s render path. Verified by measurement rather than patched on suspicion.
  • Both session interruptions cost roughly a wave each. Builders now commit after every deliverable, which is why nothing was lost the second time.
  • The .docx corpus is public real-world documents. The 59 .docx files in ~/Downloads are personal and are deliberately not used.
