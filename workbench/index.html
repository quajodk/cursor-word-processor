Decisions on the record

Editor engine

ProseMirror, used directly — not Tiptap, not Lexical

Pure decorations are load-bearing for AI diffs, diagnostics and blame. Lexical and Quill lack them; Tiptap's auto-schema fights the OOXML mapping.

The docx tension

Splice the original zip; never regenerate it

Turns 'how much OOXML can we model?' into 'how little must we touch?'. An unedited round-trip is byte-identical, and fidelity degrades only in proportion to what was actually edited.

Anchors

Exact in-session, fuzzy only for externally-edited files

While the doc is open we observed every change, so identity needs no guessing. Sequence alignment is reserved for files edited by another tool — that split is what makes the problem tractable.

Confidence floor

Drop formatting rather than risk misapplying it

A dropped style is a visible bug the writer can fix; a misapplied one silently corrupts a document they trusted.

Diagnostics

harper.js in a worker, behind an LSP-shaped seam

Offline, Apache-2.0, works unchanged in web v1 and Tauri v2. The LSP shape makes adding a second checker cheap.

Perf honesty

A measurement that covers only part of a path may fail a budget but may never certify a pass

A headless process cannot see the DOM half of a keystroke. Reporting it as 'pass' would manufacture confidence in a number that never measured the thing it names.

Notes

  • The gate is currently RED, deliberately and correctly: importing large Word documents takes p99 3.35s against a 1.2s budget. A 84ms average across the whole corpus had hidden this — the large documents are the bottleneck.
  • Two real bugs were found in the perf harness itself while wiring it: it discarded warm-up samples twice, which silently emptied the sample array and reported 'no measurement' instead of a number.
  • Both session interruptions cost roughly a wave each. Builders now commit after every deliverable, which is why nothing was lost the second time.
  • The .docx corpus is public real-world documents. The 59 .docx files in ~/Downloads are personal and are deliberately not used.
